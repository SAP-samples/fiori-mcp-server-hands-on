# Create CAP Project and Fiori List Report App based on Image

1. In Copilot, choose **Agent mode**.
    ![agent mode](./images/agent-mode.png)

2. Upload Image (manage-travels-list-report.png) to the copilot context and execute the task.

    ![context](./images/context.png)

    ![upload context](./images/upload-context.png)

3. Copy and paste the following prompt into the task input and execute the task:

    ```
    Generate a new CAP project and SAP Fiori app based on Image attached to the context.
    Include technical key and business key for all entities.
    Create implementation plan first, then proceed with confirmation.
    Consult available MCP servers.
    ```

    ![execute prompt](./images/execute-prompt.png)

4. Copilot prepares an implementation plan.

    <img src="./images/imp-plan1.png" alt="copilot" width="80%"/>

    <img src="./images/imp-plan2.png" alt="copilot" width="80%"/>

5. When prompted to proceed with the implementation plan, confirm by typing "Yes" or "Proceed".

6. Click **Allow** when prompted to run Bash commands.

    <img src="./images/bash-approve.png" alt="copilot" width="80%"/>

> [!NOTE]
> The implementation plan generated by Copilot may differ from the example shown above. The above image is just for reference.

7. Review the files and content created by Copilot, then click **Keep** to accept them.

    <img src="./images/file-changes.png" alt="copilot" width="80%"/>

8. If Copilot reaches the maximum number of requests allowed per turn in agent mode, click **Continue** to resume the implementation.

    ![max request](./images/max-request.png)


9. After completing all the to-dos/tasks, Copilot confirms the successful creation of the CAP project and Fiori app.

10. The application should automatically open in your browser, displaying a travel list report application that matches the list report Image.

    ![application preview](./images/application-preview.png)

## Troubleshoot

1. Application preview does not open automatically in the browser:

    - Stop any running processes using `Ctrl+C`, then delete all terminal windows, including any hidden ones.

        ![close terminal](./images/close-terminal.png)

    **Option 1:**
    
    - Right-click on the Fiori app and select the watch script. **Important:** Keep the application preview terminal running—do not close it.

        ![preview app](./images/preview-application.png)

        ![watch travel](./images/watch-travel.png)

    **Option 2:**
    
    - You can start the watch script manually:
        - Open the **package.json** file.
        - Right-click on the **watch** script and select **Run Script**.

        ![watch script](./images/watch-script.png)

2. `ENOSPC: System limit for number of file watchers reached`

    ![system limit error](./images/system-limit-error.png)

    Add the following script to the **package.json** file:

    ```
    "cds": {
        "watch": {
            "excludes": [
                "**/node_modules",
                "**/target",
                "db/data.sqlite"
            ]
        }
    }
    ```
    ![package json](./images/package-json-entry.png)

3. If HTTP port 4004 is already in use, press `Enter` to restart preview with a different port number.

> [!NOTE]
> Ensure that you either use 4004 or the system-assigned port for the preview. Check terminal instances and delete any duplicate processes running to preview the application.

4. If the application prompts for authentication, use username: `dummy` and password: `dummy`.

5. In the browser, if your application does not load or displays a blank page:

    - Open Developer Tools in your browser to check the error message by pressing `F12` or `Ctrl` + `Shift` + `I` (Windows/Linux) / `⌘` + `Option` + `I` (macOS).

        ![developer tools](./images/developer-tools.png)

    - For a 404 error, enter the prompt:
        ```
        Error: Could not load metadata: 404 Not Found
        ```
        - Press `Enter` and Copilot will fix the service URL path issue.

    - For a 200 error, enter the prompt:
        ```
        Check if the EDM JSON expression ($edmJson) syntax is incorrect and validate it using CAP MCP.
        ```
    - If 200 error still exists, enter this prompt:
        ```
        Remove all instances of EDM JSON ($edmJson) expression syntax from the code.
        ```
